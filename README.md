🪙 Ledger — Modern Expense Tracker
A sleek, local-first web application designed to track personal finances, manage assets, and monitor daily transactions with a neumorphic dark UI[cite: 1].
✨ Features
Add & Delete Expenses: Seamlessly log new transactions with custom details and remove obsolete records[cite: 1].
Real-Time Financial Totals: Instantly calculate and display total assets versus total expenses[cite: 1].
Timeframe Filters: Easily toggle views across Week, Month, and Year periods[cite: 1].
Live Search Utility: Quickly look up specific transactions using the search bar[cite: 1].
Local Storage Persistence: Automatically saves all records locally so data is fully restored after page refreshes[cite: 1].
🛠️ Built With
HTML5 — Semantic structure[cite: 1]
CSS3 — Neumorphic design system, custom properties, and modern layout[cite: 1]
JavaScript (ES6+) — Dynamic DOM manipulation and state handling[cite: 1]
Browser Storage API — Client-side local data persistence[cite: 1]

Clone the repository:
Bash

Bash
